# Use of artificial intelligence

The Space Apps submission form asks teams to say which AI tools they used and how. This file keeps that record up to date.

| Tool | What it was used for |
| --- | --- |
| Claude (Anthropic) | Writing the application code, the tests and the documentation together with the team's developer; designing the visual identity (the "Flight Data File" style, colours, layout, the mission patch logo and the icons, all written as CSS and SVG code); drafting the team guide; searching for and summarising NASA sources. |

Before submitting, the team reviews the code and checks every number shown in the app against the source it cites. No raster images, audio or video in the project were generated with AI. The logo, icons and body drawing are vector graphics written as SVG code with Claude's help. **To check before submitting:** whether the submission guide counts code-drawn graphics like these as "AI-generated images" that need a visible AI watermark. If it does, add the watermark to the patch and the drawing.
