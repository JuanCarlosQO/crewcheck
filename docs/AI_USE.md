# Use of artificial intelligence

The Space Apps submission form asks teams to say which AI tools they used and how. This file keeps that record up to date.

| Tool | What it was used for |
| --- | --- |
| Claude (Anthropic) | Writing the application code, the tests and the documentation together with the team's developer; designing the visual identity (the "Earthlight" style chosen by the team from AI-made mockups: colours, layout, the CrewCheck mark, the Earth and orbit graphics and the icons, all written as CSS and SVG code); drafting the team guide; searching for and summarising NASA sources. |

Before submitting, the team reviews the code and checks every number shown in the app against the source it cites. No raster images, audio or video in the project were generated with AI. The mark, icons, Earth graphics and body drawing are vector graphics written as SVG and CSS code with Claude's help. **To check before submitting:** whether the submission guide counts code-drawn graphics like these as "AI-generated images" that need a visible AI watermark. If it does, add the watermark to the mark and the drawing.
