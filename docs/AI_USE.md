# Use of artificial intelligence

The Space Apps submission form asks teams to say which AI tools they used and how. This file keeps that record up to date.

| Tool | What it was used for |
| --- | --- |
| Claude (Anthropic) | Writing the application code, the tests and the documentation together with the team's developer; drafting the team guide; searching for and summarising NASA sources. |

Before submitting, the team reviews the code and checks every number shown in the app against the source it cites. No images, audio or video in the project were generated with AI. If that changes, they must carry a visible AI watermark, as the submission guide requires.
